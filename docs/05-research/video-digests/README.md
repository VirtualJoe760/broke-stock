# Video digests

Structured digests of videos (and other sources) we evaluate. Each digest is a factual record of *what the source did and claimed*; the credibility judgment and the extracted, testable strategy live in the [strategy library](../../04-strategies/README.md).

## Workflow

1. Get the transcript (paste it, or auto-transcribe).
2. Write a digest here using the shape below.
3. Extract a strategy into the library at L0.
4. Link them both ways.

## Digest shape

- Source (creator, link, date), and creator's relevant background
- What they actually built (architecture / tooling)
- The strategy (instruments, horizon, rules)
- Claimed results
- Honest read (leverage / regime / sample / survivorship)
- What we adopt into `broke` vs. what we reject
